# CV · Alejandro Hernández Castillo

Aplicación web y PWA iPhone-first para presentar el currículum, experiencia y proyectos de Alejandro Hernández Castillo.

## Dirección de diseño

Interfaz minimalista, responsive y accesible, inspirada en patrones públicos de diseño de plataformas Apple: claridad, jerarquía, tipografía del sistema, superficies translúcidas, navegación adaptativa y estados simples.

No utiliza activos propietarios ni pretende replicar una interfaz de Apple.

## Funciones

- CV web responsive.
- Experiencia profesional y formación.
- Portfolio de proyectos con enlaces a GitHub.
- Modo claro/oscuro.
- PWA instalable.
- Service worker con caché básica.
- Navegación adaptada a móvil y escritorio.
- Soporte para reducción de movimiento.

## Publicación

El repositorio está preparado para GitHub Pages. En GitHub: Settings → Pages → Deploy from branch → main → root.

## Criterio de candidatura

El texto evita afirmar empleo, asociación o representación de OpenAI. La página se presenta como candidatura personal y enlaza proyectos propios verificables.
